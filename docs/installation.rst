Installation
============

Requirements
------------

- Python 3.10+
- PyTorch 2.0+
- Transformers 4.35+
- PEFT 0.7+

From PyPI
---------

.. code-block:: bash

   pip install tta-torch

.. note::

   The package has not been published to PyPI yet. Install from GitHub instead.

From GitHub
-----------

.. code-block:: bash

   pip install git+https://github.com/Griffith-7/TTA-Torch-of-Self-Tuning-Inference.git

Editable Install
----------------

Clone the repository and install in development mode:

.. code-block:: bash

   git clone https://github.com/Griffith-7/TTA-Torch-of-Self-Tuning-Inference.git
   cd TTA-Torch-of-Self-Tuning-Inference
   pip install -e .
